# Screenshots

Drop the images here, then declare them in `screenshots.json` at the repository
root (1–8 relative paths, no leading `/`, no `..`). Without that file the
marketplace extracts images from `README.md` instead.

| File | What to capture |
| --- | --- |
| `01-settings-row.png` | Settings → General, with the restart row and its hint line visible |
| `02-confirm.png` | The same row after the first click, armed as `确认重启？` |

PNG, light or dark theme, roughly 1200–1600px wide is plenty — the storefront
scales them.
